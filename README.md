# go-template

The starting point for a Go project. Don't copy it by hand: run `devbox run -- task new` in [go-baseline](../go-baseline), which copies it, renames it and checks it.

It holds no example code. The architecture, with examples, is in `BASELINE.md`, which go-baseline generates and `CLAUDE.md` imports, so AI agents read it in every project.

| Path | What `new` does with it |
|---|---|
| `cmd/app` | Command: renamed to `cmd/<name>`. Pure library or adapters: removed, and a root `doc.go` added. |
| `.golangci.yml`, `BASELINE.md`, `.github/workflows/check.yml`, `Taskfile.yml` | Regenerated by `go tool go-baseline write -kind <kind>` |
| `Taskfile.project.yml` | Command: kept, with its `build` task; add the project's own tasks here. Pure library or adapters: removed |
| `CLAUDE.md` | Kept; add the project's own notes below the import |
| `README.md`, `LICENSE` | Replaced and removed |

The settings come from go-baseline, which `go.mod` pins as a tool; `devbox run -- task check` fails if the project drifts from them.
